```python
def fibonacci(n):
    """
    Returns the n-th Fibonacci number using an iterative approach.
    """
    if n <= 0:
        return 0
    elif n == 1:
        return 1
    
    a, b = 0, 1
    for _ in range(2, n + 1):
        a, b = b, a + b
    return b
```

The iterative approach is significantly more efficient than naive recursion for calculating Fibonacci numbers. In the recursive implementation, each call branches into two more calls, resulting in an exponential time complexity of O(2^n). This becomes computationally infeasible even for relatively small values of n, such as n = 40.

The iterative version you've provided has a linear time complexity of O(n) and constant space complexity of O(1), making it much more scalable and practical for real-world applications where performance is critical.
